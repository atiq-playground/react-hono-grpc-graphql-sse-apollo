# Grill With Docs

Ask focused, concrete questions until requirements, constraints, edge cases, and acceptance evidence are precise enough to plan.

Use `/domain-modeling` only when the conversation actually settles domain vocabulary or a decision that meets the ADR threshold. Do not create documentation merely because the interview occurred, and do not modify authoritative root docs unless the user explicitly authorizes that scope.
